# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report privately to **webmaster@semek.org**. Include:

- What the problem is and what an attacker could achieve.
- Steps to reproduce, or a proof of concept.
- Affected version, commit, or deployment.

You can expect an acknowledgement within a few days. Once a fix is available,
the issue is disclosed in `CHANGELOG.md` under `Security`.

## Supported Versions

Only the latest released version receives security fixes, unless stated
otherwise in the project README.
